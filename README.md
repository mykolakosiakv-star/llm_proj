# Програмний комплекс «LLM-AutoBench» (v2.1)

**Кваліфікаційна магістерська робота:**  
*«Дослідження ефективності застосування великих мовних моделей для автоматизації відповідей на типові запити користувачів»*  
*(Study of the Effectiveness of Large Language Models in Automating Responses to Common User Queries)*

**Прикладне призначення:**  
Інженерна система підтримки прийняття рішень (СППР) та багатофакторного бенчмаркінгу для вибору оптимальної конфігурації `Модель LLM + Провайдер (Прямий API / OpenRouter / Локальний Ollama) + Стратегія промптингу (P1–P5)` при автоматизації першої лінії клієнтської та технічної підтримки.

---

## 1. Ключові можливості програмного комплексу

1. **5-ступеневий конвеєр автоматизації та маршрутизації звернень:**
   $$\text{Запит користувача} \longrightarrow \text{Класифікація (Jaccard Stem)} \longrightarrow \text{Пошук нормативних фактів (RAG)} \longrightarrow \text{Конструювання промпту (P1–P5)} \longrightarrow \text{Виклик LLM API} \longrightarrow \text{Верифікація якості та Шлюз ескалації}$$

2. **Мультидоменна база типових запитів (Ground Truth Dataset) та JSON-імпорт:**
   - **108 верифікованих типових запитів** у 4 галузевих сферах:
     - `fintech` — **Фінтех та інтернет-банкінг «FinCloud»** (60 запитів у 5 категоріях `INF`, `NAV`, `PRC`, `TRB`, `CLR`);
     - `it_helpdesk` — **ІТ-підтримка та SaaS Helpdesk** (16 запитів `IT-*`);
     - `ecommerce` — **E-Commerce та служба доставки** (16 запитів `EC-*`);
     - `telecom` — **Телеком та інтернет-провайдер** (16 запитів `TL-*`);
   - вбудована підтримка **масового JSON-імпорту** власних корпоративних баз типових запитів через інтерфейс (`POST /api/queries/import`);
   - розширена чернетка на 105 запитів (`data/proposed/expanded_queries_draft.json`) із підвищеною часткою ескалаційних сценаріїв та запитів-пасток (prompt injection, неіснуючі тарифи).

3. **5 досліджуваних стратегій формування промптів ($P_1 \dots P_5$) із версіонуванням:**
   - **P1** — Базовий (*Zero-Shot Direct*);
   - **P2** — Рольовий з предметними обмеженнями та контекстом бази знань (*Role + Domain Constraints / RAG*);
   - **P3** — Навчання за зразками (*Few-Shot 2-shot*) із гарантованим захистом від витоку поточного запиту в приклади;
   - **P4** — Ланцюжок міркувань і самоперевірка (*Chain-of-Thought + Self-Verification*);
   - **P5** — Структурований вивід із явним шлюзом ескалації (*Structured Output + Escalation Gate*).

4. **Живе виявлення моделей (Dynamic Model Discovery) та гнучка маршрутизація API:**
   - пряма інтеграція з **6 провайдерами**: `Google AI Studio (Gemini)`, `Groq Cloud`, `OpenRouter`, `OpenAI`, `Anthropic`, `Ollama (Local)`;
   - автоматичне опитування живих ендпоінтів `/models`, перевірка балансів (зокрема точного балансу `OpenRouter`), відображення рідних і OpenRouter-лімітів (`RPM`, `RPD`, `TPM`, контекстне вікно, тарифи `$/1M токенів`);
   - індивідуальне перемикання маршруту моделі (`Прямий API ↔ OpenRouter`) та інтерактивне відновлення під час збоїв API у серійних експериментах (очікування та повтор, перемикання маршруту на льоту, зміна судді, довиконання перерваних серій та відкладене дооцінювання суддею).

5. **Науково верифіковане ядро оцінювання (Evaluation Engine):**
   - **Фактична повнота ($FC$, %)** з канонічною нормалізацією чисел `normalize_numbers()` та синонімічними групами `{"id", "any_of"}`;
   - **Детектор фактичних галюцинацій (`detect_hallucinations`)** — виявлення вигаданих сум, відсотків, лімітів та неіснуючих розділів меню в лапках;
   - **Лексико-семантична схожість ($SS$, %)** — чисті `stem_cosine_pct` та `rouge_l_f1_pct` без штучних множників;
   - **Бінарний чек-лист формату ($FMT$, %)** для кожної стратегії `P1–P5` на шкалі $[0, 100\%]$;
   - **Стійкий шлюз ескалації** з матрицею плутанини ($\text{TP, FP, FN, TN}$, $\text{Precision, Recall, } F_1$, критичний $\text{FN-rate}$) та нециклічним рівнем безпечної автоматизації ($AR$, %);
   - **Ортогональний композитний індекс якості $Q_{\text{det}}$** без змішування із затримкою мережі + аналіз чутливості ваг за $\tau$ Кендалла;
   - **Якірна рубрика `rubric_v1.yaml` (на основі NIST AI RMF 1.0)** зі сліпим LLM-суддею (крос-сімейна політика + SQLite-кешування) та ручною експертною переоцінкою.

6. **Модуль підтримки прийняття рішень (Decision Support Advisor) та ROI-калькулятор:**
   - **4 цільові профілі впровадження**: *«Збалансований SaaS»*, *«Критична безпека: Фінтех / Медтех»*, *«Швидкий чат-бот першої лінії»*, *«Бюджетна масова підтримка»*;
   - автоматичний вибір переможця `Модель + Промпт` із текстовим інженерним обґрунтуванням, рейтинговою таблицею (Leaderboard) та **аудитом ризиків і вразливостей**;
   - **інтерактивний калькулятор економічної ефективності (ROI)** — розрахунок кількості автоматично закритих тікетів на місяць, вивільнених людино-годин операторів (`FTE`), місячних витрат на API токенів (`$/1M`) і чистої економії бюджету компанії в `$` та `%`.

7. **Непараметрична статистика та експорт для Пояснювальної записки:**
   - 95% перцентильні бутстреп-довірчі інтервали (`seed=42`), медіана, $IQR$, вибіркове СКВ з поправкою Бесселя ($N-1$);
   - парний критерій знакових рангів Вілкоксона, критерій Фрідмана з поправкою Холма–Бонферроні та розмір ефекту Cliff's $\delta$;
   - Парето-фронти в координатах `Якість vs Затримка` та `Якість vs Вартість ($/1M)`;
   - прямий експорт та завантаження готових таблиць у форматах **CSV (Excel UTF-8 BOM), Markdown та LaTeX**.

│   ├── import_annotations.py            # Імпорт ручних оцінок експертів у БД

## 3. Швидкий запуск та перевірка

1. **Запуск веб-сервера (порт 8000):**
   ```powershell
   python run.py
   ```
   або напряму через `uvicorn`:
   ```powershell
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```
   Відкрийте у браузері: **http://127.0.0.1:8000**

2. **Запуск повного набору автоматичних тестів (`16/16` тестів, без платних викликів API):**
   ```powershell
   pytest tests.py -v
   ```

3. **Запуск аудиту еталонного датасету:**
   ```powershell
   python scripts/audit_dataset.py
   ```

4. **Детальна технічна документація:**
   Повний опис архітектури, схеми БД, математичних формул, алгоритмів, методів та HTTP API наведено у файлі **[TECHNICAL_PASSPORT.md](./TECHNICAL_PASSPORT.md)**.

## 4. Стилі інтерфейсу

Файл `app/static/tailwind.css` зібраний локально, тому інтерфейс працює без доступу до CDN Tailwind. Якщо в `index.html` або `js/*.js` з'явилися нові класи, перезберіть його (потрібен Node.js):

```powershell
cd scripts/tailwind
npm install --no-save tailwindcss@3.4.17
npx tailwindcss -c tailwind.config.js -i input.css -o ../../app/static/tailwind.css --minify
```
